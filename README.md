# 🌱 EcoTrack - Eco Habit Tracker

EcoTrack is a simple frontend web application that helps users
track their daily eco-friendly habits.

## Features

- Daily eco-friendly habit tracking
- Eco score calculation
- Completed habit counter
- Weekly progress visualization
- Random eco-friendly tips
- Data storage using browser localStorage
- Responsive and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
